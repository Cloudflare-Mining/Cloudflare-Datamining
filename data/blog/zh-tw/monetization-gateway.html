今天，我們宣佈推出 Cloudflare Monetization Gateway，這是一個引擎，將賦予 Cloudflare 客戶能力，為任何受 Cloudflare 保護的資產收費：網頁、資料集、API 或 MCP 工具。 

它將提供一個單一控制平面，用以管理您應用程式中的付款政策和存取控制，同時透過在邊緣處理付款驗證和強制執行，保護您的源站免受高額付款流量衝擊。上線初期，款項將透過 x402 以穩定幣進行結算。x402 是一項開放通訊協定，由我們聯合 25 家以上的產業領導者透過 x402 Foundation 共同建構。

不斷演變的網路商業模式

30 年來，網際網路一直建立在一個簡單的經濟契約上：以內容換取人類的注意力。這種注意力透過廣告、訂閱和電子商務來變現。這種交換模式為我們所知的網際網路提供了支撐。 

然而，隨著智慧體成為網際網路的主要使用者，這套模式正在瓦解。智慧體不會觀看廣告，也不需要為了存取各種工具而維持月度訂閱。它們可能只讀取一次網頁或資料串流，取用所需資訊後便離開。放眼整個網路，AI 爬蟲每為網站帶回一名訪客，其自身請求內容的次數往往高達數百甚至數萬次。 

這個現實要求一種新模式：一切皆按用量計費。如果注意力與電子商務正從網站轉向 AI 驅動的系統及 AI 編寫的軟體，那麼智慧體就應該為其所需的輸入付費——無論是訓練資料、推斷內容、開發人員工具，還是 API 呼叫。對軟體而言，最自然的計價單位是「請求次數」、「詞元 (Token) 數」或「任務成果」，而非「席次」或「月份」。以下是幾個可能的應用場景：

  • 每次網路搜尋收費幾美分，按每次呼叫計費
  • 上傳端點收取 0.001 美元基本費，外加每 MB 0.01 美元
  • 每次解決的支援升級收費 0.99 美元，僅在工作成功時才付款

這與當答案引擎使用創作者內容時付費給創作者的概念相同——每當內容或資源被使用時，都能透過為此目的打造的公正機制，實現價值的公平交換。人們常想像智慧體會購買網域這樣的高價值資產，但智慧體的大部分支出其實發生在最終交易（結帳）之前的環節，且單價要低得多。

網際網路的某些領域早已採用這種模式。雲端服務與 API 多年來一直按呼叫次數或小時計費，但僅限於已知買家：使用者註冊後，獲得 API 金鑰，然後產生按用量計費的帳單。內容則大多跳過付費，轉而依賴廣告。這些商業模式一直無法支援未經驗證的買家進行小額交易，因為過去的支付軌道成本過高且結算耗時。一旦價格低於某個門檻，收取款項的成本甚至會超過款項本身的價值。

過去，按用量計費的實作極為困難。企業實際上必須兼任支付公司的角色，自行建立會計系統，以穩健且可稽核的方式追蹤內部使用情況。追蹤這些用量需要對後端系統進行大規模改造。因此，許多企業選擇按席次計價，因為它更簡單，且往往利潤更高。 

智慧體顛覆了這種動態。單一智慧體可以全天候完成整個團隊的工作量，使得與實際消耗量脫鉤的固定一次性費用顯得不合時宜。同時，智慧體可以毫無摩擦地進行數千次小額支付，若要求人類逐一核准每筆付款，則會造成難以承受的負擔。按用量計費的價格區間，正是智慧體的生存之道，也是穩定幣小額支付大展身手的舞台。這是因為穩定幣（如 Open USD 和 USDC）允許買家在網際網路上轉帳微小金額，僅產生可忽略的手續費，且結算時間不到一秒。這是當今其他支付軌道無法實現的。

這就是我們可以提供協助的地方。Cloudflare 多年來一直在為我們自己的帳務系統和客戶的分析建構基於用量的計費系統。憑藉我們作為買賣雙方之間代理層的地位，我們能大幅簡化網路資產按用量計費的實作流程。如下圖所示，在 Cloudflare 支援按用量計費後，付款憑證可以直接嵌入請求本身，使付款驗證與請求路徑合而為一。

而這將為您帶來的益處是：計量、支付交換與結算等環節均無需在您的源站上進行。留給您的，是真正重要的事——您的規則、您的價格，以及您的營收。您無需處理買家入駐流程，也無需搭建計費系統；您只需設定規則，智慧體買家便會為其用量付費。

x402 快速回顧

去年的內容獨立日 (Content Independence Day)，我們讓網站擁有者能一鍵控管哪些 AI 爬蟲可以存取其內容；接著推出的依爬行次數付費，更讓他們能向爬蟲收取費用。Monetization Gateway 則是下一步：我們不再只針對內容向爬蟲收費，而是讓您能針對任何資源向任何呼叫者收費——從 API、資料到 MCP 工具呼叫皆然，且您完全不需要自建支付系統。

x402 是一套開放通訊協定，旨在讓「透過 HTTP 付款」成為可能，其名稱源自終於被實際運用的 402 狀態碼。x402 的交換流程十分簡潔：用戶端請求一個受支付閘控管的資源。伺服器不會直接回傳資源，而是回應 402 Payment Required（需要付款），並附上一小段負載，標明價格、接受的資產與付款地址。用戶端完成付款後，再次傳送請求並附上付款證明。經由 Facilitator（促進者）驗證後，伺服器便會回傳資源。這一切都在普通的 HTTP 請求與回應中完成，無須重新導向結帳頁面，也無須呼叫獨立的支付 API。結算以點對點 (P2P) 方式進行，買家傳送的款項會直接存入賣家的錢包。我們設計 Monetization Gateway 時，致力於將支付額外開銷降至最低，目標是實現次秒級的支付結算。

x402 支付流程：AI 智慧體 ↔ API 伺服器 ↔ 區塊鏈，來源：GitHub 上的 x402 README

x402 有兩大特性，使其成為機器支付的理想選擇。首先，由於通訊協定本身幾乎不增加額外負擔，付款金額可以極小，甚至低至不到一美分。其次，買家無需在賣家處開立帳戶，因為付款行為本身就是認證。x402 雖然與底層軌道無關，但它與穩定幣是天作之合——穩定幣能以不到一秒的速度完成結算，手續費僅為零點幾美分，且無退款風險。

Monetization Gateway 的功能

Monetization Gateway 將提供一套靈活的支付規則 API，讓您能精準定義呼叫者必須在何時付費才能存取您的數位資源。

其運作方式如下。詞元、API、MCP 工具呼叫與資料都已經流經這條路徑。您將能精確決定哪些流量需要付費。您只需在一個簡單、專用的產品 API 中編寫運算式（與您為其他 Cloudflare 規則編寫運算式的方式類似），即可強制執行您的決策。Monetization Gateway 將依托 Cloudflare 遍佈全球 330 多座城市的網路進行擴展，這意味著 x402 的交握驗證將在離買家最近的地方發生。這不僅能降低請求延遲，更能保護您的來源伺服器。 

以下是幾項預計推出的功能範例：

  • 針對特定 REST 動詞收費：針對特定路由的呼叫要求付款，例如針對 /api/premium/* 的每一次 GET 或 POST 請求收取 0.01 美元。
  • 變動式計價：針對不同複雜度的任務收取不同費用，例如影像產生任務的收費可高達 2 美元，具體金額取決於所消耗的運算資源。
  • 僅向未經驗證呼叫者收費：攔截來源伺服器回傳的 HTTP 401「未授權」回應，改為回傳 402「需要付款」，並附上價格與付款指示。

當請求符合規則時，Monetization Gateway 會在放行前驗證付款狀態。您可以在儀表板上設定這些規則，或透過 Cloudflare API 與 Terraform 以「基礎架構即程式碼」的方式管理，讓一個付費端點成為您基礎架構設定的另一環。

Monetization Gateway 初期將允許使用者要求買家以穩定幣支付服務與資源費用。賣家累積的穩定幣，可用於自身的交易，或兌換為等值法幣存入銀行帳戶。使用 Monetization Gateway 能有效擴大您產品的可觸及市場。透過該 Gateway，智慧體可以請求您的資源、獲知價格、完成付款並取得回應。無須註冊、無須 API 金鑰、無須預先建立關係。您將能決定需要掌握買家多少資訊，並可靈活要求智慧體透過 Web Bot Auth 進行身分驗證，針對其既有帳戶套用按用量計費。

我們的願景

Monetization Gateway 將把「請求」轉化為「付款」，為 Cloudflare 客戶開創新的營收機會，但這僅僅是個開始。

智慧體是一種能代表使用者自主行動的軟體，且它們正開始獨立運作。不久後，它們將擁有自己的錢包，並在無須人類介入的情況下購買所需資源：無論是資料集、API 呼叫、工具，還是運算區塊。其中部分資源將是免費的；部分則需要透過已驗證的智慧體身分，證明自己是誰以及代表誰行事。還有許多資源將同時要求身分驗證與付款，而 Cloudflare 是少數能讓這一切在單一請求內完成結算的平台——我們會在來源伺服器接收到呼叫前，先完成智慧體驗證、規則套用與付款檢查。如此一來，智慧體將成為網際網路的主要買家，而請求本身就是交易。

現今網際網路上有巨量價值在流動，卻未被變現或變現不足。這並非因為沒人願意付費，而是因為從未有合適的工具能對其收費。每一次有價值的 API 呼叫、每一個答案、每一次智慧體發起的工具叫用，都蘊含價值，但如今幾乎都沒有被收費。這正是我們眼前的機遇，也是 Monetization Gateway 將要解鎖的潛力。

這就是我們致力打造的未來：一個以智慧體為優先，且內建網際網路級結算機制的網際網路。在這裡，創造出有價值內容的人，能自動獲得使用該內容的軟體所支付的報酬。在這裡，規模最小的新創 API 也能與網路上最大的企業站在同一起跑點上，接觸相同的買家；獨立創作者也能從使用其作品的大型語言模型手中獲得收益。這就是網際網路的下一代商業模式，而我們正在打造支撐它的基石。
