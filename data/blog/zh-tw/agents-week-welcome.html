本週是 Agents Week。

當我們開始構思並規劃這週的活動時，我們反覆思索一個更宏觀的問題：支援這個智慧體新時代究竟代表什麼？而一個專為智慧體打造的基礎又該是什麼模樣？這讓我們回到一個更簡單的框架：Agent Cloud 是什麼？ 

但我們很快就發現，我們的框架錯了。不是因為這是個不該問的問題，而是因為我們問錯了對象——我們問的是自己，而不是我們的智慧體。這不再關乎我們以及我們的想法，而是關乎智慧體需要什麼。 

簡言之，這就是 Agents Week 的核心所在。 

我們今日所擁有的雲端，以及它所依託的網路，都是為人而建。每一層都假設有人類在觀看：為吸引人類目光而設計的頁面、供人類點擊瀏覽的儀表板、針對我們閱讀與決策方式所調校的介面。但智慧體不是這樣運作的。它們不會分心、不會疲倦或感到疲勞……而且它們在速度、結構與存取方面，有著自身獨特的需求。

一個 Agent Cloud 必須同時做到兩件事。一方面，它要為我們鋪好通往智慧體原生未來的道路，讓各項基礎元件從一開始就是為智慧體而建，而不是從人類工具事後改造而來。另一方面，現實上，它也必須接住當下的現實，扮演一座翻譯層，橋接現有人類導向的網路，與我們正邁向的智慧體導向網路。

這正是接下來五天的核心主軸：一套同時為智慧體與人類設計的雲端，應該長什麼模樣？兩者又該如何互動？本週將圍繞以下面向展開探討：這對您需要的底層元件與執行層意味著什麼；更新後的「自主式軟體開發生命週期」；組織如何透過安全控管，讓員工與智慧體都能安全地互動；這一切將如何形塑「自主式網路」；最終，所有討論都會回歸到當今智慧體與人類共存的真實場景中。

回到那個問題：您的智慧體希望從 Agent Cloud 獲得什麼？與其直接複製貼上我們從自家智慧體那裡得到的回答，我們更鼓勵您去親自問問自己的智慧體，並分享任何有趣的觀察與回覆。您可以參考下面這段提示詞，但也歡迎您自行探索屬於您的答案：

作為一個智慧體，你希望從 Agent Cloud 獲得哪些支援？請從以下幾個面向想像：儲存與運算雲端、你所需的執行與儲存底層元件、你的開發生命週期（ADLC，類似 SDLC，但將人類移出迴圈）、在組織內安全存取記錄系統以完成深度工作的能力，以及網路層面（包含發現、存取、支付等機制）。

請在這裡回覆告訴我們您的智慧體說了什麼，我們很期待看到各種回應！
