如今，AI 智慧體要嘗試新的 API 並不容易。它們通常得瀏覽專為人類（而非智慧體）設計的登入頁面、聯絡真人來新增付款方式、產生 API 金鑰，然後再想辦法呼叫 API。

這個流程對智慧體來說非常困難，原因有兩個：智慧體沒有穩定的識別碼來註冊 API，也沒有原生方式來支付 API 費用。因為缺乏這些，它們常常難以加入軟體服務，這限制了智慧體商務的成長。AI 智慧體經常完全放棄這些任務，把註冊、付款方式和 API 金鑰產生等工作丟回給人類。這使得智慧體很難嘗試和比較許多 API。

為了解決這個問題，我們建立了 Cloudflare Wallets。從今天起，您可以為您的帳戶​申請一個 Cloudflare Wallet 名稱，這將提供一個獨特的使用者名稱，幫助您更好地與商家建立聯繫。很快，您將能夠設定並使用您的 Cloudflare Wallet 來支付 API 和內容的費用。

本月稍早，我們宣布推出了 Monetization Gateway，以幫助 Cloudflare 客戶從他們的網站和應用程式中獲利。Monetization Gateway 將支援使用 x402 通訊協定進行小額支付，該通訊協定允許將付款附加於 HTTP 請求中。這些小額支付能涵蓋從 AI 推斷、資料到內容的各種用途。若您希望針對 Monetization Gateway 及其他​相容於 x402 通訊協定的端點所提供的服務進行付款或收款，則需要一個錢包。 

Cloudflare Wallets 將讓您能夠儲存穩定幣、購買服務，並在整個網路上接收資金。每個擁有錢包的帳戶也將能夠為其智慧體建立虛擬錢包 (Virtual Wallets)，使它們能夠購買 API、MCP 工具、內容等。您將能夠為您的虛擬錢包定義防護機制（例如額度、允許清單和最大交易金額），以幫助您的智慧體安全地從您的帳戶中花費資金。這能讓您的智慧體以低摩擦、風險受控的方式試用大量 API。錢包使用者將可以選擇分享他們的 Cloudflare Wallet 名稱，這將在他們與商家互動時提供一個穩定的身分。

建構雙向的智慧體市場

Cloudflare 的 Monetization Gateway 將允許符合條件的 Cloudflare 客戶以無頭 (headless) 方式向智慧體買家銷售他們的資源（例如內容或 API）。但要讓這個市場真正發展起來，智慧體需要更多工具來以機器原生方式向商家購買。Wallets 將為 Cloudflare 的智慧體 SDK 增加另一個工具，使 AI 智慧體能夠輕鬆使用小額支付購買必要的 API 和內容。

Cloudflare Wallets 將分為兩種類型：帳戶錢包 (Account Wallets) 和虛擬錢包 (Virtual Wallets)。

帳戶錢包是為人類設計的，他們是 Cloudflare 帳戶的擁有者和使用者。他們將能夠新增資金、將支出委派給由智慧體管理的虛擬錢包，並在需要時提取資金。 

相對地，虛擬錢包是為智慧體設計的，並透過 API 金鑰運作。在虛擬錢包中，智慧體將能夠根據其權限花費資金。其最大支出將受限於帳戶錢包擁有者設定的限額。這個架構賦予智慧體代表使用者行動的自由，無需持續的人工核准，同時限制智慧體超支的能力。

自由探索的空間

虛擬錢包之所以令人振奮，是因為它們將讓智慧體做它們最擅長的事：探索數十或數百種服務，並為特定用例找出最佳選擇。透過 x402 進行的穩定幣小額支付，將讓智慧體無需帳戶就能輕鬆嘗試 API，以極低的摩擦力測試新選項。虛擬錢包上的支出上限，其設計目的是讓人類能夠讓智慧體在安全的支出限額內自主探索。這些限制看似約束，但出乎意料地，它們反而賦予了智慧體更多自由。如果一個智慧體只負責 10 美元，您對其花費的擔憂會比它負責 1,000 美元時少得多。如果嘗試一個 API 只需花費幾美分，那麼 10 美元就綽綽有餘，足以探索和評估許多選項。

一旦您或您的智慧體選定了一個要使用的 API，您在帳戶錢包中設定的政策將作為虛擬錢包的成本控制。想給每位員工每週 100 美元的 AI 推斷預算嗎？只需在帳戶錢包中存入足夠餘額，並為每位員工建立遵循此規則的虛擬錢包即可。任何超出虛擬錢包額度的使用者，都可以向有權限修改帳戶錢包的人類申請手動覆寫。

我們希望讓帳戶錢包的支出政策既彈性又穩固，無須每日進行主動監控。當發生異常狀況（例如支出速度異常飆升）時，人類便能介入審查並確認一切是否按預期運作。如果支出是有意的，帳戶錢包的管理員可以提高上限或核准一次性注入資金；如果是無意的，那麼虛擬錢包的注資限制政策就成功發揮了防護作用。

我們致力於讓這些錢包的資金進出變得極致簡單。初期我們會在支援的地區提供便捷的資金進入和贖回管線，符合資格的使用者也將能使用穩定幣自行注資作為替代方案。網際網路的轉變不會在一夜之間完成，但鑑於目前​網路流量已有多數來自機器人，我們很高興能為智慧體與商家提供一流的智慧體商務工具。

不僅僅是支付

讓人類能將權限委派給智慧體，使其輕鬆買賣服務，是一個很好的起點。但在商家與智慧體互動的過程中，這種「委代關係」往往並不明顯。今日，當一個智慧體造訪您的網站時，您對這位「使用者」可能一無所知，儘管它實際上是代表某個人或組織在行動。這種「歸屬關係」的缺失，對許多傳統的網路商業模式構成了挑戰。向個人或組織提供一週免費試用或註冊積分很容易，但要提供給缺乏穩定身分的智慧體就很困難——尤其當一個人可以隨時衍生出數十個智慧體時更是如此。

我們透過 cloudflare.pay 將錢包與 Cloudflare 帳戶連結，以解決這個問題。​cloudflare.pay 將允許智慧體選擇性地表明身分，因為它們的身分是帳戶的委託代表。例如，一個研究型智慧體可以擁有 research.example.cloudflare.pay 這樣的名稱，讓商家清楚知道它是來自特定組織的智慧體。這種做法將讓智慧體保有連貫且持久的身分，為各方帶來更佳的體驗。智慧體完全可以自行決定是否宣告身分，而企業也可以自行決定是否優先與已知身分的智慧體進行交易。

智慧體識別碼應具備人類可讀性

我們認為，應對智慧體的方式將類似於應對 VPN：如果某人身分不明，不代表他天生不可信，但他需要付出更多努力來證明自己。這也是我們推出 Turnstile 及其他 Bot Management 內部計畫來偵測機器人的原因。我們的身分基元將建立在這些既有成果之上。例如，​Web Bot Auth 已允許智慧體透過金鑰對註冊其身分。而綁定 Cloudflare Wallets 的 ID，則讓這組金鑰對變得人類可讀。

我們深知，智慧體身分標準正快速演變，這也是我們希望保持方法簡單的原因。我們為原本不太易讀的金鑰對提出了一個易於理解的標識符，類似於 DNS 中使用的 URL 與 IP 位址配對。我們並非要定義特定的架構或其他驗證系統，只想讓身分便於記憶、易於宣告。隨著 x402 Foundation 的相關計畫逐步發展出用於豐富智慧體身分的架構，我們將積極採納，並鼓勵他人跟進。

智慧體商務的未來

在 Cloudflare，我們希望提供智慧體商務成功所需的全部基石。Monetization Gateway 將讓賣家無須建置傳統支付基礎架構也能收款；Wallets 將讓買家能透過智慧體以無頭方式付款；身分機制則讓商家能與表明身分的買家溝通，或強制執行身分驗證要求。

這些基石將共同打造出一個屬於網際網路的無頭市場。如果您對此感到興奮並想參與其中，​現在就可以領取您的專屬名稱。我們非常期待看到您建構的成果，以及如何透過它們變現。
