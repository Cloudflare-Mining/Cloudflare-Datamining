通过简单几次点击，Monetization Gateway 让域名所有者可以向智能体收取访问其网站、API、MCP 工具或数据集的费用。立即在 Cloudflare 仪表板 申请访问权限。

智能体的兴起与机器支付的普及

如今，大多数软件企业通过订阅或预付费积分销售产品。这些商业模式要求买家进行相当大的前期经济投入，因此买家只能订阅少数符合预算的服务。然而，这一商业模式与互联网流量的主要来源——智能体——的运作方式并不契合。

智能体追求结果，无论是来自直接问题还是隐性需求。为了实现一个目标，智能体可能会访问新站点、调用 MCP 工具或摄取数据流。全球各地的企业都希望处于关键路径中，帮助智能体获得更好的结果。这有助于企业在新用户所在之处触达他们、从为智能体回答所做的贡献中获得报酬，并在无头智能体商务领域占据领先地位。

企业需要将商业模式与智能体的消费模式对齐，才能抓住这一机遇。支付必须与智能体的消费单位相匹配：按请求、按搜索查询、按 token 计费。当今主流的支付基础设施无法支持这一需求。这些支付基础设施假设买家能够接受高延迟、只进行大额交易，以及买家是卖家已知或可识别的实体。智能体所需恰恰相反：低成本、快速且可靠的支付基础设施，能够在最小人工干预下安全扩展。

卖家和买家都将被激励去将商业模式与消费对齐，并使用能帮助他们实现这一目标的支付网络。如今，稳定币交易及其底层区块链网络已能够满足这些要求。随着时间推移，我们可能会看到现有网络引入新方案或新型支付网络涌现。Monetization Gateway 的存在就是为了确保卖家能专注于自身产品，买家能获得可预期的购买体验。

基于Monetization Gateway进行开发

Monetization Gateway 让卖家能够对 Cloudflare 网络背后的任何资源向智能体按用量收费。它专为每次请求即代表一次使用的资源而设计，如 API、工具和数据。高价值内容则不同：一个页面可能被爬取一次，却被使用千次。为此，Pay Per Use 提供了一个由经过验证的可信买家组成的网络，每次使用都会上报并付费。

该网关使用 HTTP 402 Payment Required 状态码，使买家可以通过 HTTP 内联方式为资源提供支付，与请求资源本身同步进行。这是一个重要的区别，因为不存在跳转到结账页面的重定向，也无需调用单独的支付 API。

卖家定义哪些请求需要付款、费用金额以及付款接收地址。买家收到支付指令，签署授权，并在支付结算后获得资源。

最简单的理解方式是将其视为“智能体专用付费墙”。卖家只需几秒钟和几次点击即可上线，确定要收费的目标群体，并确保买家在完成支付前无法访问相关资源。

除了易于实施之外，我们还为卖家提供了一整套开箱即用的定价和变现功能。您可以编写匹配请求任何部分（如 URL、请求头或查询参数）的定价规则，并从多种定价方案中选择。其余工作由我们来处理：通过 Coinbase x402 Facilitator 进行支付验证和结算，处理失败和重试，提供分析报告，以及跟进 x402 协议的变更。支付在 Base 区块链上以 USDC 结算，USDC 是一种与美元挂钩的稳定币。未来，我们计划帮助卖家让自己的服务对智能体可见，公开所有交易日志，支持更多支付基础设施，并整合身份原语。

让我们看看客户今天是如何在生产中使用它的。

Cloudflare AI Gateway：为推理付费

Cloudflare 的 AI Gateway 是一个控制平面和模型市场，让开发者只需一个 API 密钥即可访问数百个AI模型。我们的目标是在生态系统中运营最丰富的模型目录，并让尽可能多的客户使用。AI Gateway 允许客户购买积分，可用于所有 AI Gateway 消费。但随着越来越多的智能体持有钱包，以维持积分余额作为唯一使用方式会带来不必要的摩擦。

从今天起，美国本土Cloudflare客户可以通过添加请求头 PAYMENT-METHOD: x402，在请求时为特定模型集的推理付费。详细说明请参阅我们的 AI Gateway 开发人员文档。未来，您可以期待看到HTTP 402状态码原生集成到更多 Cloudflare 基础设施产品中。

$ curl -iX POST "https://api.cloudflare.com/client/v4/accounts/$CLOUDFLARE_ACCOUNT_ID/ai/run" \
  --header "Authorization: Bearer $CLOUDFLARE_API_TOKEN" \
  --header "Payment-Method: x402" \
  --header "Content-Type: application/json" \
  --data '{
    "model": "z-ai/glm-4.7-flash",
    "input": {
      "max_tokens": 9001,
      "messages": [
        {
          "role": "user",
          "content": "What is Cloudflare?"
        }
      ]
    }
  }'

AI Gateway 拥有复杂的定价引擎，负责每个 token 的计费方式。我们联合设计了 Monetization Gateway，以满足源端控制定价的需求。启用此配置后，Monetization Gateway 直接从卖家（AI Gateway）请求定价信息。对 AI Gateway 而言，这意味着可以依赖其现有定价模块，无需在 Monetization Gateway 中维护规则目录。

Ceramic.ai：为网络搜索付费

“网络是为人类买家而建的——那些注册并输入信用卡的人。智能体需要自主行动，支付正是实现这一目标的方式。搜索是每个智能体最先需要的功能之一，因此它也应该是智能体最先能够购买的功能之一。”——Dr. Anna Patterson，创始人，Ceramic.ai

如果推理是思考，那么搜索就是现实检验。Ceramic.ai 提供专为智能体构建的网络搜索 API。Ceramic.ai 维护着一个包含超过 400 亿个页面的专有索引，并针对机器调用方对其技术栈的每一层进行了优化，可在 50 毫秒内返回搜索结果。以这样的速度，智能体可以在整个任务过程中反复搜索。

这使搜索成为智能体原生支付的天然契合点。搜索是智能体购买的最具弹性的事物之一。一个简单的问题可能只需一次查询，而复杂的调查任务可能需要数百次。当智能体可以自行为搜索付费时，就不再需要根据预先设定的预算来分配查询次数。它可以根据任务决定搜索深度，在需要更多证据时多花费一些。

Ceramic.ai 使用 Monetization Gateway 的固定定价变现方案，让智能体无需 API 密钥即可执行搜索。使用演示和 Ceramic.ai 文档了解更多。

Stocktwits：为股票信号付费

“智能体改变了数据的消费方式。客户无需签署订阅或谈判企业许可证，智能体可以在需要时请求所需的确切内容。对个别请求收费的能力为 Stocktwits 开辟了一种全新的数据开放方式。”——Howard Lindzon，创始人兼 CEO，Stocktwits

当股票开始波动时，交易者首先问的问题之一是：其他人都在说什么？

18 年来，这一对话一直在 Stocktwits 上进行。Stocktwits 于 2008 年推出，率先引入了现金标签（如 $NET），以围绕个股组织市场对话。如今，超过 1000 万人使用 Stocktwits 跟踪市场、分享想法，并了解其他投资者的讨论。

由于 Stocktwits 专为投资者打造，它能实时呈现散户投资者正在关注和讨论的内容。Stocktwits 将这些活动转化为信号，包括：

  • 情绪：关于某只股票代码的近期帖子主要是看多还是看空
  • 消息量：某只股票代码相对其典型活动产生了多少讨论
  • 关注者：有多少 Stocktwits 用户关注某只股票代码，衡量散户持续关注度
  • 趋势：哪些股票代码正在最快速地吸引关注

这些信号长期以来通过 Stocktwits 现有的数据产品提供。Monetization Gateway 为新型客户——即需要按需获取市场背景的 AI 智能体——创造了额外的分发渠道。例如，一个监控投资组合或研究投资标的的智能体，可以查看 $NET 周边讨论是否升温、情绪是否偏向看多或看空，或有多少投资者关注该股票代码。无需传统数据许可证，开发者只需为其智能体实际发出的个别请求付费。

最初，Stocktwits 为这些请求建立了一个独立的面向智能体的路径，并在其前端部署了 Cloudflare 的 Monetization Gateway。现有的 API 和企业数据产品保持不变。每个请求单独定价，使 Stocktwits 能够在保留现有数据产品和许可模式的同时，让 AI 智能体可以访问其市场信号。立即查看他们的文档开始使用。

API2PDF：为 API 访问付费

API2PDF 是一个 REST API，帮助开发者从 HTML 和 Office 文档生成 PDF。自 2018 年上线以来，API2PDF 观察到越来越多的 AI 智能体将开发者引导至其服务，现已将其视为一级客户。

API2PDF 的基于消费的定价模型根据完成每个请求所需的带宽和计算资源向客户收费。以前，客户在使用该服务前需要创建账户并获取 API 密钥。第一个月后还需提供信用卡，导致转化率下降超过50%。API2PDF 现在使用 Monetization Gateway，当用户或智能体在没有API密钥的情况下发出请求时，返回 HTTP 402 响应。由于每个请求的计算和带宽成本是可变的，API2PDF 使用可变定价告知智能体单次请求可能产生的最高费用。客户完成支付后，API2PDF 处理请求并仅结算实际消耗量。

智能体面临与开发者相同的自建还是购买的决策。需要 PDF 的智能体可以消耗 token 自行生成，或花费不到一分钱委托 API2PDF 这类专业 API 来正确完成。
