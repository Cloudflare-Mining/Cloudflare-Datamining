今天，我们很高兴地宣布与 Anthropic、Asana、Atlassian、Block、Intercom、Linear、PayPal、Sentry、Stripe 和 Webflow 合作，推出一系列在 Cloudflare 平台上构建的全新远程 MCP 服务器，让 Claude 用户能够管理项目、生成发票、查询数据库，甚至部署全栈应用，而无需离开聊天界面。

自从 Anthropic 在 11 月推出模型上下文协议 (MCP) 以来，人们对它的关注与日俱增，几乎每天都会发布新的 MCP 服务器。而且是有充分理由的！MCP 是 AI 代理跨平台沟通的关键协议，并且有助于定义 AI 代理如何与工具的交互方式，以采取行动并获得更多上下文信息。

但迄今为止，最终用户必须在其本地计算机上安装 MCP 服务器才能使用它们。如今，随着 Anthropic 宣布推出集成功能，用户可以像访问网站一样访问 MCP 服务器：输入 URL 并开始访问。

Cloudflare 一直致力于构建工具来简化远程 MCP 服务器开发，以便客户的工程团队能够专注于为其应用构建 MCP 工具，而无需管理复杂的协议。如果您想了解在 Cloudflare 平台上部署远程 MCP 服务器有多么容易，我们很高兴地告诉您，只需一键单击即可部署 MCP 服务器（此类服务器已预先构建，且支持最新的 MCP 标准）。

但您不必轻信我们的说法，亲自体验吧！行业领军企业正积极利用这种简单易用性，通过在 Cloudflare 平台上构建 MCP 服务器来为用户提供全新的 AI 驱动体验，现在您也可以这样做， 只需单击“部署到 Cloudflare”即可开始。

MCP：为下一代应用提供支持

人们并不总是期望每一项服务，无论是商店、房产中介还是其它服务，都拥有一个网站。但随着越来越多的人能够访问互联网，这种情况迅速变成了现实。

我们目前正处于类似的转型期，每个 Web 用户都可以使用 AI 工具，并利用这些工具来完成许多任务。如果您是开发人员，现在如果要编写代码，您首先想到的可能就是使用 Claude 之类的工具。那么，如果 Claude 帮助您编写代码，它也能帮助您部署代码，这似乎合情合理。

或者，如果您不是开发人员，如果 Claude 帮助您制定了食谱，那么它也能帮助您订购所需的食品杂货。

借助远程 MCP，所有这些场景目前都有可能实现。正如首批在 Web 上拓展业务的企业具有先发优势一样，首批以 MCP 为先导的企业很可能从中获益。

用户可以越快速地体验到产品的价值，他/她们就越有可能取得成功、升级并继续使用您的产品。通过 MCP 将服务与代理连接起来，如此一来，用户只需提出自己的需求，代理会处理其余事宜，从而让用户可以更快速地体验到“顿悟时刻”。

采用 MCP，运用 AI 优先方法来提供服务

采用 MCP 的企业会快速获得显著效益：

降低准入门槛

并非每个用户都有时间来熟悉仪表板或通读文档，以便了解您的产品。借助 MCP，他/她们无需这样做。他/她们只需描述自己的需求，其余事宜交由代理来处理。

打造个性化体验

MCP 可以跟踪用户的请求与交互，以便根据用户的使用模式和偏好来调整未来的工具调用。如此一来，您可以根据每个用户实际使用产品的方式，轻松提供更个性化、更相关的体验。

顺其自然推动升级

AI 代理可以解释更高级别的计划如何有助于特定用户实现其目标，而无需依赖特征比较表。

发布新功能和集成

您无需在内部构建所有集成或体验。通过 MCP 来公开发布工具，您可以让用户将产品连接到其各自的其他技术栈。代理可以整合不同提供商的工具来实现集成，而无需您直接支持所有第三方服务。

为什么要在 Cloudflare 平台上构建 MCP？

自 MCP 推出以来，Cloudflare 一直在分享如何帮助开发人员轻松构建和部署远程 MCP 服务器，从简化协议复杂性到处理身份验证和数据传输，再到支持完全状态化的 MCP 服务器（默认情况下，这些服务器处于闲置状态时会进入“休眠”），以便最大限度地降低闲置成本。

我们将继续定期发布更新，增加对 MCP 标准最新变更的支持，让您可以更轻松地将服务器投入生产：

  • 支持新的 Streamable HTTP 传输：MCP 服务器现在可以搭配使用最新的 Streamable HTTP 传输方式与 SSE，从而确保与最新标准兼容。我们也已更新 AI Playground 和 mcp-remote 代理，为您提供远程 MCP 客户端，让您能够轻松测试新的传输方式。
  • MCP 服务器支持 Python：现在，您可以使用 Python（而不仅仅只是 JavaScript/TypeScript），在 Cloudflare 平台上构建 MCP 服务器。
  • 优化文档、入门模板和部署流程：我们已添加了新的快速启动模板，扩展了文档以介绍新的传输方式，并且分享了根据我们的经验教训来构建 MCP 服务器的最佳实践。

但我们认为，与其向您讲述，不如直接向您展示我们的客户已经构建的具体内容，以及这些客户选择将其 MCP 部署在 Cloudflare 平台的原因。

Asana

如今，员工和团队需要使用许多不同的应用和服务来执行日常工作任务。通过投资 MCP，Asana 能够随时随地满足用户需求，实现由代理驱动的各种工具和工作流程之间的互操作性。用户可以使用自然语言与 Asana Work Graph 交互，从 MCP 客户端获取项目更新、搜索任务、管理项目、发送评论以及更新截止日期。

用户将能够无缝编排和集成不同的工作，例如，将其他应用中的项目计划或会议记录转换为 Asana 中完全分配的任务集，或者将 Asana 任务直接拖入支持 MCP 的 IDE 中实施。这种灵活性让横跨各种系统来管理工作变得比以往任何时候都更加轻松、快捷和自然。

为了加快发布我们的第一方 MCP 服务器，Asana 使用 Cloudflare 工具进行构建，利用其基本的基础设施，在这个快速发展的领域中快速、可靠地行动。

“Asana 始终致力于帮助各个团队轻松地协调工作。MCP 将 Asana Work Graph 直接连接到诸如 Claude.ai 这样的 AI 工具，使 AI 成为工作管理中真正的队友。我们的集成将自然语言转换为结构化工作，例如，从会议记录创建项目或将更新提取到 AI 中。利用 Cloudflare 基础设施进行构建，让我们能够快速部署，处理身份验证和扩展，同时专注于为用户打造最佳体验。”– Asana 首席技术官 Prashant Pandey

Atlassian

现在，Jira 和 Confluence Cloud 客户可以通过 Atlassian 远程 MCP 服务器（测试版），直接从 Anthropic 的 Claude 应用安全地进行数据交互。应用托管在 Cloudflare 基础设施上，用户可以汇总工作、创建问题或页面，以及执行多步骤操作，同时确保数据安全并且处于权限范围内。

用户无论身处何地，都可以在使用 Claude 来访问 Jira 和 Confluence 中的信息，以便：

  • 汇总 Jira 工作项或 Confluence 页面
  • 直接通过 Claude 创建 Jira 工作项或 Confluence 页面
  • 让模型一次性执行多项操作，例如批量创建问题或页面
  • 使用 Claude 可以访问的多个不同来源的上下文，丰富 Jira 工作项
  • 等等！

Intercom

Intercom 日益认识到人工智能 (AI) 的变革作用。Intercom 开发的 AI 代理 Fin 目前能够为 Anthropic 等领军企业自主处理 50% 以上的客户支持对话。采用 MCP，可以更轻松地将 AI 连接到内部工具和系统，从而创造更高的商业价值。

例如，客户对话会提供关于产品使用方式和客户体验的宝贵见解。但是，这些数据通常被锁定在支持平台内。Intercom MCP 服务器将解锁这个丰富的客户数据源，让企业内部使用 AI 工具的任何用户都可以访问这些数据。例如，工程师可以利用源自 Intercom 的对话历史记录以及用户数据，在 Cursor 或 Claude Code 等工具中更高效地诊断和解决问题。

Sentry

使用 Sentry MCP 服务器，开发人员可以直接通过其 IDE 或 Claude 之类的 AI 助手来查询 Sentry 上下文，以获取跨项目甚至是单个文件的错误和问题信息。

开发人员还可以使用 MCP 创建项目、获取设置信息、查询项目和组织信息，以及利用这些信息为 Sentry 设置其应用。随着我们不断完善 MCP，团队将能够从 AI 代理 Seer 中引入根本原因分析和解决方案信息，并尝试简化 Sentry 功能的检测，例如跟踪和异常处理。

通过将其托管在 Cloudflare 平台上并使用远程 MCP，我们能够避免在本地运行过程中遇到的许多复杂问题，例如扩展或身份验证。远程 MCP 让我们可以直接利用 Sentry 自身的 OAuth 配置。此外，Durable Object 支持也让我们能够在 MCP 内维持状态，这在非本地运行时至关重要。 

“Sentry 始终致力于以开发人员为中心，让他/她们能够更轻松地维持生产软件稳定运行。在 AI 时代，这一点将会变得更加重要。开发人员会利用 MCP 之类的工具，将技术栈与 AI 模型和数据源集成。我们选择在 Cloudflare 平台上构建 MCP，是因为我们不仅拥有共同的愿景，即：让开发人员可以更轻松地交付软件，而且都致力于确保团队能够构建并安全运行下一代 AI 代理。调试这些集成过程中产生的复杂交互变得越来越重要，而 Sentry 提供了快速诊断和解决问题所需的、必不可少的可见性。MCP 将关键的 Sentry 上下文直接集成到开发人员的工作流程，让团队能够一致地构建并部署可靠的应用。”- Sentry 首席产品官兼联合创始人 David Cramer
