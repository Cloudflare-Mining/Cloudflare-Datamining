目前，AI 智能体很难尝试新的 API。智能体往往不得不浏览为人类而非为智能体设计的登录页面、联系人类添加支付方式、生成 API 密钥，最后弄清楚如何调用该 API。

智能体难以完成这个流程，有两个原因：一是缺少可用于 API 注册的稳定身份标识，二是没有原生的支付能力。因此智能体往往难以接入软件，从而制约了智能体商务的发展。AI 智能体经常完全放弃这些任务，将注册、支付方式和 API 密钥生成交还给人类。这使得智能体很难尝试和比较多个 API。

为此，我们创建了 Cloudflare Wallets。从今天开始，您可以为自己的账户​申领一个 Cloudflare Wallet 用户名，它将提供一个独特的用户标识，以便您更好地与商家进行互动。很快，您将能够设置并使用您的 Cloudflare Wallet 来支付 API 和内容费用。

本月早些时候，我们推出了  Monetization Gateway，以帮助 Cloudflare 客户为他们的网站和应用获取收益。Monetization Gateway 将支持使用 x402 协议的微支付，使支付操作能够直接绑定到 HTTP 请求。这些微支付功能可用于支付从 AI 推理、数据到内容等多种费用。如果您想为 Monetization Gateway 以及其他 x402 兼容端点背后的服务付款或收款，您将需要一个钱包。 

Cloudflare 钱包将允许您在网络上存储稳定币、购买服务和接收资金。每个拥有钱包的账户还可以为其智能体创建虚拟钱包，使其能够购买 API、MCP 工具、内容等。您将能够为虚拟钱包定义安全护栏（如额度限制、允许列表和最大交易金额），以帮助智能体能够安全地使用您账户中的资金。这将支持您的智能体以低摩擦和风险可控的方式尝试多种 API。Wallet 用户将可以选择分享我 Cloudflare Wallet 用户名，这将在与商家互动时提供稳定的身份标识。

打造双边智能体市场

Cloudflare 的 Monetization Gateway 将允许符合条件的 Cloudflare 客户将其资源（如内容或 API）以以无头方式出售给智能体买家。但要使该市场真正发展起来，智能体需要更多工具以机器原生的方式从商家购买。Wallets 将为 Cloudflare 的Agents SDK 增加另一种工具，使 AI 智能体能够轻松使用微支付购买所需的 API 和内容。

Cloudflare 将有两种类型的钱包：账户钱包和虚拟钱包。

账户钱包是为 Cloudflare 账户的所有者和用户设计的。他们将能够添加资金，委托智能体管理的虚拟钱包进行支出，并根据需要提取资金。 

虚拟钱包，则专为智能体设计，通过 API 密钥操作。在虚拟钱包中，智能体将能够根据其权限使用资金。其最大支出将由账户钱包所有者设定的限额确定。该框架允许代理代表用户自主行动，无需持续的手动审批，同时防止智能体过度支出。

探索的自由

虚拟钱包令人兴奋之处在于，它将使智能体能够发挥其最大优势：探索数十个乃至数百个服务，并为特定场景找到最佳方案。通过 x402 协议进行的稳定币微支付将简化 API 试用流程，无需创建帐户，以最小摩擦测试新的选项。虚拟钱包上的支出上限设计使人类可以让智能体在安全的支出限制范围内自主探索。虽然这些限制表面上是约束，但反而为智能体提供了更大的自由度。如果智能体的限额是 10 美元，那么您对其支出的担忧将低于 1000 美元的情况。如果尝试一个 API 的成本仅为几美分，那么 10 美元足以用于探索和评估多个选项。

一旦您或您的智能体选定了要使用的 API，您在帐户钱包中设置的政策将充当虚拟钱包的成本控制机制。想为每位员工配置每周 100 美元的 AI 推理预算吗？只需为帐户钱包配置适当的余额，并为每位员工创建配置该规则的虚拟钱包。超出虚拟钱包支出上限的任何人都可以向拥有帐户钱包修改权限的人员申请手动覆盖。

我们希望使人们能够为帐户钱包轻松制定灵活但严格的支出政策，从而无需每日持续监管。当出现异常情况时，例如支出意外快速增加，人员将能够审查并确认一切是否按预期运作。当支出确认为有意行为时，帐户钱包管理员可以提高限额或者一次性增加资金。如果支出属于无意行为，则向虚拟钱包添加资金的支出政策通过实施上限而发挥了作用。

我们正在努力使注入资金和使用这些钱包尽可能简单。我们将首先在支持的地域范围内推出简便的资金出入机制，并为符合条件的用户提供稳定币自助充值的选项。虽然互联网不会在一夜之间完全转变，但由于​大部分网络流量现已由智能体驱动，我们很高兴为智能体和商家提供一流的智能体商务工具。

超越支付本身

允许人类向智能体委派权限以轻松购买和销售服务，这是一个有益的起点。但这种委派对于商家来说在与智能体互动时并不总是显而易见的。如今，如果一个智能体来访问您的网站，尽管该智能体代表某个个人或组织行事，您可能对他们作为用户的身份知之甚少。这种身份识别的缺失对许多传统网络商业模式构成了挑战。向个人或组织提供一周免费试用或注册积分很简单。由于智能体缺乏稳定身份，且每个人可以创建和控制多个智能体，向它们提供同样的福利将变得困难。

我们的解决方案是将钱包通过 cloudflare.pay 关联到一个 Cloudflare 帐户。 cloudflare.pay 将允许智能体选择性地识别自己的身份，因为其身份是该账户的一个委托。某个研究智能体可能位于  research.example.cloudflare.pay，让商家知道这是来自特定组织的智能体。这种方法将允许智能体保持一致和持久的身份，提升所有参与方的体验。智能体完全可以选择是否声明其身份，同时商家决定是否优先与已知智能体进行交易。

智能体标识符应为人类可读

我们认为对智能体的处理方法将类似于 VPN ：身份未识别，并不意味着其本质上不可信，但他们需要提供更多证明。因此我们拥有  Turnstile 和其他来自 Bot Management 的工具来检测机器人。我们的身份原语将以上述过去的工作成果为基础进行构建。例如，​Web Bot Auth 已经允许智能体通过密钥对注册其身份。附加到 Cloudflare 钱包的 ID 使这个密钥对变得易于人类读取。

我们知道，智能体身份标准正在快速演变，因此我们希望使这个方法保持简单。我们提议为不太易读的密钥对配备一个人类可读的标识符，类似于​ DNS 中使用的 URL 和 IP 地址配对。我们不打算制定特定的数据架构或验证标准。我们只希望让身份易于记忆并便于声明。随着用于充实智能体身份的数据架构在 ​x402 Foundation 的推动下逐步完善，我们承诺采纳这些架构，并有意鼓励业界同样这样做。

智能体商务的未来

Cloudflare 希望为智能体商务的成功提供所有必要的基础组件。Monetization Gateway 将为销售者提供一种无需建立传统支付基础设施即可收款的方法。Wallets 将提供通过智能体以无头方式付款的方式。Identity 将允许商家与已确认身份的买家进行沟通，或执行身份验证要求。

所有这些构建模块将为互联网创建一个无头市场。如果您对此感兴趣并希望参与其中， 欢迎立即申领您的用户名。我们期待看到您构建并变现的项目。
