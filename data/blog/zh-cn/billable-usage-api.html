Agents Week 关注正在发生的变革——AI 智能体编写代码、部署 Workers 并预配基础设施。这一转变改变了您需要掌握的信息。如果某个程序正在您的 Cloudflare 账户中产生费用，您需要了解其支出详情——全天各时段、按产品细分，并以另一个程序可直接处理的格式提供。仪表板是适合人类的方式，但不适用于自动化程序。

因此，我们面向自助服务账户推出了新的 Billable Usage API。该 API 通过单一端点返回您账户的使用量与成本明细，并按产品和服务周期进行细分。它涵盖账户中所有按量计费的 Cloudflare 产品，包括 Workers、R2、D1、Workers AI、Vectorize、Images 和 Stream，一个调用即可获取。如果您已在使用 FinOps 工具链，这些列名应该并不陌生。

curl https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/billable-usage \
  -H "Authorization: Bearer $CLOUDFLARE_API_TOKEN"
curl "https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/billable-usage?from=2026-02-01&to=2026-02-15" \
  -H "Authorization: Bearer $CLOUDFLARE_API_TOKEN"

您将收到 HTTP 200 OK 响应，以及 Content-Type: application/json，响应体中包含使用量记录。目前，使用量和成本数据每日更新，而我们正致力于提供更实时的数据。

返回内容

响应中的每一行对应您账户中一个产品的一个计费周期。

  • ServiceName 和 ServiceFamilyName——产品（“Workers”系列下的“Workers Standard”，以及“R2”下的“R2 Storage”等）。
  • ChargePeriodStart / ChargePeriodEnd——该行所涵盖的时间段。
  • PricingQuantity 和 ConsumedUnit——您的使用量，以我们的计费计量单位表示（GB-月、GB-秒、请求数等）。
  • ContractedCost——该期间的费用，以 BillingCurrency 为货币单位。
  • CumulatedPricingQuantity 和 CumulatedContractedCost——当前计费周期内的累计金额。
  • ZoneId / ZoneName —— 当使用量归属于特定区域时返回。

我们在匹配 FOCUS 规范方面的进展

匹配 FOCUS 命名规范是经过深思熟虑做出的选择。AWS、Azure、Google Cloud、Oracle 以及越来越多的 SaaS 提供商已提供以 FOCUS 格式导出数据，所有主流成本管理工具均已支持该规范。不过，我们目前尚未宣称完全符合规范：响应体中仍缺少规范要求的几个列。完全符合规范已列入我们的路线图。请将此视为第一步：当前是熟悉的形态，下一步是完全符合规范。

Cloudflare 支出与其他云服务支出并列呈现：我们与 Vantage 的合作

我们与 Vantage合作，实现了原生 Cloudflare 集成。Vantage 是一个基础设施成本管理平台，可从超过 30 个服务提供商（涵盖 AI、云和 SaaS 提供商）获取成本和使用数据，并将其整合为统一视图，以便进行报告、归集和优化。通过此集成，您的用量数据将汇入您已用于管理其他基础设施的同一套成本报告、预算和成本告警系统中。

Vantage 使用具有计费读取权限的只读 API 令牌连接到 Cloudflare。连接后，Vantage 每日提取您的计费使用数据，按产品（例如 Workers 和 R2）、区域和账户进行分类，以便您了解哪些产品驱动了支出增长，并将费用归集到相应的团队和服务。

本集成支持的工作流示例：

  • 跨服务商分配。按产品、区域和账户对 Cloudflare 费用进行分组，然后使用虚拟标签（Virtual Tags）按团队或产品线进行归集，将 Cloudflare 费用与 AWS、Azure 及其他服务商费用纳入同一份报告。
  • 异常检测。Vantage 成本告警（Cost Alerts）监控每个已连接的服务商，当支出偏离基线时通过 Slack 或电子邮件通知您，Workers 或 R2 的支出异动也会像其他服务商一样被及时捕获。
  • FinOps 智能体与 MCP。在控制台中向 Vantage FinOps 智能体提问，例如“上周所有服务商中最大的成本驱动因素是什么？”，或者通过 Vantage 托管的 MCP 服务器从 Claude 或 ChatGPT 查询相同的数据。Cloudflare 支出将与其他已接入服务商的数据一并呈现。

在 Vantage 控制台中连接您的 Cloudflare 帐户，您的开支会与您运行的其他服务或产品一同显示。无需手动导出、上传发票，也无需维护额外的仪表板。 

该 FOCUS 标准化 API 也可与其他金融科技工具配合使用。

我们为何构建此 API

智能体所做的不只是编写代码。它们还会部署 Workers、预置 R2 存储桶，并管理 D1 数据库。一旦您允许程序以编程方式访问 Cloudflare 账户，就必须能够通过同样的方式监控由此产生的成本。无需等到月底，而是贯穿全天、按产品细分、以程序可直接处理的结构化格式提供。

Billable Usage API 就是这种形态。客户多年来一直在要求我们提供编程方式的用量查询能力。财务团队希望将支出拉取到自己的系统中，并将成本归因于内部项目、团队，甚至最终客户。开发人员希望有一个可以嵌入脚本的 curl 命令。这些工作流中的每一个，过去都需要依赖截图或手动导出。如今只需一次 HTTP 调用，或在 Vantage 中进行配置。

下一步

  • 更细粒度的时间窗口。目前，API 返回收费周期行，对于大多数产品而言是以天为单位。我们正在探索为适用产品提供更实时的费用明细。
  • 预测。 CumulatedContractedCost 告诉您当前账单周期的消费情况。我们希望帮助您预测最终将达到的总费用水平。而且不仅在账户级别，还包括产品级别。
  • Enterprise 客户覆盖。首个版本仅支持自助服务。Enterprise 合同的等效体验正在开发中。

立即试用

该端点今天起向所有自助账户开放。获取具有Billing Read权限的 API 令牌，用 curl 命令发起调用，即可获得按产品划分的当前计费周期信息。完整参考信息可在 Cloudflare API 文档中查阅。如需与您的其他云支出费用一同查看，请在 Vantage 控制台中连接您的 Cloudflare 账户。
