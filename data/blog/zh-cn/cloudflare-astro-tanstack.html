为什么选择 Astro 和 TanStack？投资前端的未来

我们支持 Astro 和 TanStack 的决定是经过深思熟虑的。这两个项目分别代表着对未来 Web 开发截然不同却又相辅相成的愿景：一个致力于重新定义高性能内容驱动型网站的架构，另一个则为构建最宏伟的 Web 应用提供全栈工具包。

Astro：面向高性能网站的开发框架

在认可技术方面，我们始终坚信行胜于言。

正因如此，我们对 Astro 的支持不仅仅是经济上的，更是基础性的。我们的开发者文档网站 developers.cloudflare.com 完全基于 Astro 运行。这可不是个小项目，而是一个重要的资源，每天有数十万开发者访问，数十位贡献者不断更新。对于这样的网站来说，性能不仅仅是一项功能，而是一项必需品。

我们选择 Astro，是因为它的核心原则与我们自身理念相符。其“默认零 JS”架构提供了内容密集型网站所需的原始性能和卓越的 SEO，确保我们的文档快速且易于查找。同样重要的是，Astro 不受框架限制，允许团队使用 React、Vue 或 Svelte 的组件，而无需担心供应商锁定。

Astro 让我们全球团队能轻松保持内容为最新，更重要的是，让我们的文档始终保持极速加载。我们此次提供赞助，正是源自切身体会到的巨大价值。

Cloudflare 的合作与支持，印证了我们共同的使命：让网络更快、更开放，对所有基于网络进行开发的人而言都更美好。——Fred K. Schott，Astro 联合创始人兼项目负责人

Webflow 赋予营销人员、设计师和开发者无拘无束的创作自由。Astro 秉承同样的理念，通过消除障碍、加速工作流程、开启全新创意可能，践行这一精神。我们与 Cloudflare 和 Netlify 携手合作，共同确保社区赖以依靠的开发工具保持开放性、可持续性，并为未来做好充分准备。

TanStack Start：助力构建宏伟应用的完整全栈框架

如果说 Astro 为内容密集型网站提供了理想的基础，那么 TanStack 则为复杂的 Web 应用程序提供了理想的引擎。TanStack 并非单一框架，而是一套功能强大、无头且类型安全的库，能够解决现代应用程序开发中最棘手的问题。

像 TanStack Query 这样的库已经成为管理异步服务器状态的行业标准，优雅地解决了缓存、后台重新获取和乐观更新等复杂挑战，而这些挑战曾经需要数千行脆弱的定制代码才能解决。同样，TanStack Router 为路由带来了完全的类型安全，消除了一整类常见的错误，而 TanStack Table 和 TanStack Form 则提供了构建复杂的数据密集型用户界面所需的强大、无头的原语。

今天，TanStack 宣布正式发布 TanStack Start 1.0 候选版本，向生产就绪迈出一大步。

TanStack Start 是一款全新的全栈框架，它将这些强大的库整合为紧密集成、企业级水准的开发体验。凭借全文档服务端渲染 (SSR)、流式传输以及“随处部署”的架构等功能，TanStack Start 专为现代无服务器边缘计算环境而设计。它既能为大型应用提供所需的强大功能与类型安全保障，又能完美适配 Cloudflare Workers 等部署环境。

有了 Cloudflare 的帮助，TanStack 可以不断提升快速、可扩展且类型安全的工具标准，为下一代 Web 应用提供支持，同时保护开发人员所依赖的开放性和自由度。——Tanner Linsley，TanStack 创建者

对我们而言，支持开放网络并非锦上添花的选项，而是践行「构建更好网络」使命的必然要求。与 Cloudflare 携手确保这些顶级项目获得资金支持，是我们当下最毋庸置疑的决定！ —— Mat B，首席执行官
