Hoy en día, es difícil para los agentes de IA probar nuevas API. En general, tienen que navegar por una página de inicio de sesión diseñada para humanos y no para agentes, contactar a una persona para agregar un método de pago, generar una clave API y luego averiguar cómo llamar a la API.

Este flujo es muy difícil para los agentes por dos razones: los agentes no tienen un identificador estable para registrarse en una API y no tienen una forma nativa de pagar las API. Debido a que carecen de estas cosas, suelen tener dificultades para integrar el software, lo que limita el crecimiento del comercio agéntico. Los agentes de IA suelen abandonar por completo estas tareas, delegan el registro, los métodos de pago y la generación de la clave API a los humanos. Esto hace que sea muy difícil para los agentes probar y comparar muchas API.

Para resolver esto, hemos creado Cloudflare Wallets. A partir de hoy, puedes obtener un identificador de Cloudflare Wallet para tu cuenta, lo que te proporcionará un nombre de usuario único para ayudarte a conectarte mejor con los comerciantes. Pronto podrás configurar y usar tu Cloudflare Wallet para pagar por el uso de API y de contenido.

A principios de este mes, anunciamos el Monetization Gateway para ayudar a los clientes de Cloudflare a recibir pagos por sus sitios web y aplicaciones. Monetization Gateway admitirá micropagos utilizando el protocolo x402, lo que permite adjuntar pagos a las solicitudes HTTP. Estos micropagos podrán pagar usos que van desde la inferencia de IA hasta datos y contenido. Si deseas pagar o recibir pagos por servicios mediante Monetization Gateway y otros puntos finales compatibles con x402, necesitarás una billetera. 

Cloudflare Wallets te permitirán almacenar stablecoins, comprar servicios y recibir fondos en toda la web. Cada cuenta con una billetera también podrá crear billeteras virtuales para sus agentes, que les permitirá comprar API, herramientas MCP, contenido y más. Podrás definir límites para tus billeteras virtuales (como una asignación, una lista de permitidos y un tamaño máximo de transacción) para ayudar a tu agente a gastar dinero de manera segura desde tu cuenta. Esto permitirá que tu agente pruebe muchas API con poca dificultad y riesgo gestionado. Los usuarios de una billetera tendrán la opción de compartir sus identificadores de Cloudflare Wallets, lo que les proporcionará una identidad estable al interactuar con los comerciantes.

Construir el mercado agéntico bidireccional

 Monetization Gateway de Cloudflare permitirá a los clientes elegibles de Cloudflare vender sus recursos (como contenido o API) de manera autónoma a compradores agénticos. Pero para que ese mercado se desarrolle verdaderamente, los agentes necesitan más herramientas para comprar a los comerciantes de manera nativa en el entorno digital. Cloudflare Wallets agregará otra herramienta al SDK de agentes de Cloudflare, lo que permitirá a los agentes de IA comprar de forma sencilla las API y el contenido necesario mediante micropagos.

Habrá dos tipos de Cloudflare Wallets: carteras de cuenta y carteras virtuales.

Billeteras de cuenta: están diseñadas para personas que son propietarios y usuarios de cuentas de Cloudflare. Podrán agregar fondos, delegar el gasto a billeteras virtuales administradas por agentes y retirar fondos según sea necesario. 

Billeteras virtuales: por el contrario, están diseñadas para agentes y operan mediante clave API. Dentro de una billetera virtual, un agente podrá gastar fondos de acuerdo con sus permisos. Su gasto máximo estará limitado por el límite establecido por el propietario de la Billetera de cuenta. Este marco les da a los agentes la libertad de actuar en nombre de los usuarios sin necesidad de aprobación manual constante, mientras limita la capacidad del agente para gastar en exceso.

La libertad de explorar

Las billeteras virtuales son emocionantes porque permitirán a los agentes hacer lo que mejor saben hacer: explorar docenas o cientos de servicios y encontrar el mejor para un caso de uso particular. Los micropagos con stablecoin a través de x402 facilitarán probar una API sin una cuenta, y permitirán a los agentes evaluar nuevas opciones con poca fricción. Los límites de gasto en las carteras virtuales están diseñados para que los agentes puedan explorar de manera autónoma dentro de límites de gasto seguros. Estos límites pueden parecer restricciones, pero en realidad, le dan a los agentes más libertad. Si un agente es responsable de USD 10, puedes preocuparte menos por su gasto que si es responsable de USD 1.000. Si una API solo cuesta unos centavos probarla, entonces USD 10 es más que suficiente para explorar y evaluar muchas opciones.

Una vez que tú o tu agente hayan seleccionado una API para usar, las políticas que establezcas en tu Billetera de cuenta actuarán como controles de costos para Billeteras virtuales. ¿Quieres darle a cada usuario un presupuesto de USD 100 por semana para inferencia de IA? Simplemente brinda una Billetera de cuenta con el saldo adecuado y crea Billeteras virtuales para cada usuario con esa regla. Cualquiera que exceda los límites de su Billetera virtual podrá solicitar una excepción manual a una persona autorizada para realizar cambios en la Billetera de Cuenta.

Queremos facilitar a las billeteras de cuenta establecer políticas de gasto flexibles pero firmes que no requieran supervisión activa diaria. Cuando ocurre algo fuera de lo normal, como un gasto inesperadamente rápido, una persona podrá revisar y confirmar si todo está operando según lo previsto. Si el gasto fue intencionado, entonces el administrador de la Billetera de cuenta podrá aumentar el límite o aprobar una inyección única de fondos. Si el gasto fue involuntario, entonces las políticas de gasto para agregar fondos a las billeteras virtuales hicieron su trabajo al imponer límites.

Estamos trabajando para que sea lo más fácil posible financiar y usar estas billeteras. Comenzaremos con formas simples de incorporar y extraer fondos dentro de las geografías compatibles, con la opción de auto-financiamiento a través de stablecoins disponible como alternativa para los usuarios elegibles. El Internet no cambiará por completo de la noche a la mañana, pero con la mayoría del tráfico en la web ahora impulsado por bots, estamos emocionados de ofrecer a los agentes y comerciantes herramientas de primera clase para el comercio agéntico.

Más allá de los pagos

Permitir que los humanos deleguen autoridad a agentes para comprar y vender servicios fácilmente es un punto de partida útil. Pero esta delegación no siempre es obvia para los comerciantes mientras interactúan con los agentes. Hoy en día, si un agente visita tu sitio web, es posible que sepas poco sobre él como usuario, a pesar de que el agente actúe en nombre de una persona o una organización. Esta falta de atribución desafía muchos modelos de negocio web tradicionales. Es fácil ofrecer una prueba gratuita de una semana o créditos de inscripción a una persona o a una organización. Es difícil ofrecer estos mismos beneficios a un agente que carece de una identidad estable, especialmente cuando una persona puede generar docenas de agentes bajo su control.

Resolvemos este problema vinculando carteras a una cuenta de Cloudflare a través de cloudflare.pay. cloudflare.pay permitirá a los agentes identificarse de forma opcional, ya que su identidad es un delegado de la cuenta. Un agente de investigación podría vivir en research.example.cloudflare.pay, lo que permite a los comerciantes identificar que es un agente de una organización en particular. Este enfoque permitirá a los agentes mantener identidades consistentes y persistentes, mejorando la experiencia para todas las partes. Será completamente opcional para los agentes decidir si declaran su identidad o no, y dependerá de las empresas decidir si quieren priorizar transacciones con agentes conocidos.

Los identificadores de agentes deben ser legibles para las personas

Creemos que el enfoque para tratar con agentes será similar al enfoque para tratar con VPN: si alguien no está identificado, no es inherentemente desconfiable, pero debe demostrar su valides. Por eso tenemos Turnstile y otras iniciativas para detectar bots dentro de la gestión de bots. Nuestro elemento primario de identidad se construirá sobre este trabajo previo. Por ejemplo, Web Bot Auth ya permite a los agentes registrar su identidad mediante un par de claves. Las ID adjuntas a Cloudflare Wallets permiten que este par de claves sea legible para las personas.

Sabemos que los estándares de identidad agéntica están cambiando rápidamente, por lo que queríamos mantener nuestro enfoque simple. Estamos proponiendo un identificador legible para las personas para un par de claves poco legible, similar a las asociaciones de URL y direcciones IP utilizadas en DNS. No estamos tratando de definir un esquema particular u otro sistema de verificación. Solo queremos hacer que la identidad sea fácil de recordar y simple de declarar. A medida que los esquemas para enriquecer la identidad agente se desarrollen a través de las iniciativas de la x402 Foundation, buscaremos adoptarlos y pretendemos alentar a otros a hacer lo mismo.

El futuro del comercio agéntico

En Cloudflare, queremos ofrecer todos los componentes necesarios para que el comercio autónomo tenga éxito. Monetization Gateway ofrecerá una manera para que los vendedores reciban pagos sin configurar una infraestructura de pagos tradicional. Las billeteras ofrecerán una forma para que los compradores paguen de manera invisible a través de agentes. La identidad permitirá a los comerciantes comunicarse con los compradores que se identifiquen o exigir requisitos de identificación.

Todos estos bloques de creación crearán una plataforma de comercio electrónico de arquitectura abierta para Internet. Si estás entusiasmado con esto y quieres participar, puedes reservar tu nombre de usuario ahora. Estamos emocionados de ver lo que construyes y monetizas.
