## Make web apps faster with intelligent, real-time routing

The Cloudflare network routes an average of 102 million HTTP requests per second, providing a unique view of traffic flow on the Internet. 

Argo Smart Routing uses this information to detect the fastest network paths, then intelligently routes customer web traffic on those paths.

## Argo Smart Routing FAQs

#### What is Argo Smart Routing?

Argo Smart Routing is a service that accelerates web application performance by detecting and routing traffic around real-time network congestion on the Internet. On average, it can make web applications 30% faster.

#### How does Argo Smart Routing work?

The Cloudflare network processes a massive volume of Internet traffic, giving it a unique view of real-time network conditions. Argo uses this information to identify the fastest available network paths and intelligently routes your web traffic over them to ensure the quickest delivery.

#### What are the main benefits of using Argo Smart Routing?

The key benefits include noticeably faster loading times for a better user experience, increased reliability and uptime by routing around congestion, and integrated end-to-end encryption to protect web traffic from attackers.

#### Can Argo Smart Routing help reduce costs?

Argo Smart Routing can reduce costs in two main ways. First, it minimizes content requests to your origin server, which lowers server load and bandwidth usage. Second, it offers tiered caching to increase cache hit rates, which further lowers infrastructure costs.

#### Why is normal Internet routing unreliable?

The Internet is a network of networks, and users of a given application may be located anywhere, meaning requests and responses have to traverse any number of these networks. Some of these networks may be experiencing exceptionally high traffic volume, just as a highway is sometimes inundated with auto traffic. Other networks might experience downtime, forcing packets to go the long way around or causing packets to be lost altogether. Argo Smart Routing eliminates these issues by using Cloudflare's proprietary real-time data about network traffic congestion to send requests and responses over only the fastest and most reliable routes possible. The result is a faster and more consistent experience for end users.
