# K2

> K2 enables applications to produce events to a durable, ordered stream. Subscribe to the stream with one or more consumers.

## Key Features

- Serverless event streams
- Durable storage with configurable retention
- Atomic batch writes
- Produce via Workers binding or HTTP
- Independent subscriptions
- At-least-once delivery

## Benefits

### Truly serverless

No clusters to manage or scale. Pay only for what you use.

### Long-term retention

Events are stored with configurable TTL, up to one month.

### Flexible consumption

Consume all events from multiple clients, distribute events across a cluster of clients, or both.

## Use Cases

### Real-time analytics pipelines

Collect clickstream, telemetry, and log events from browsers, Workers, and backend services, and process them as they arrive.

### Microservice event buses

Decouple services with a durable, ordered log. Every service can publish, and multiple consumers can read at their own pace.
