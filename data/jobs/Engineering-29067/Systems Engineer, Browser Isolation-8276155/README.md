<p><strong>Available Locations: </strong>Austin, TX (US)</p>
<p><strong>About the team</strong></p>
<p><a href="https://www.cloudflare.com/zero-trust/products/browser-isolation/">Cloudflare Browser Isolation</a> runs web content in remote browsers, helping protect users from threats while preserving a responsive browsing experience. Our team builds the Chromium-based browsing engine, remote rendering and streaming technology, and distributed services that manage browser sessions across Cloudflare’s global network.</p>
<p>You will work at the intersection of systems programming, distributed systems, and security. Engineers contribute across the product, collaborating on browser changes, service orchestration, observability, and build infrastructure.</p>
<p><strong>Scope and growth</strong></p>
<p>At this level, you will be accountable for reliable delivery within a defined component or problem area. You will make sound implementation decisions, seek help when needed, and build broader system knowledge over time. You do not need to have led an organization-wide architecture effort to succeed in this role.</p>
<p><strong>Technologies we use</strong></p>
<ul>
	<li>Browser engine: Chromium and C++.</li>
	<li>Systems programming: Rust.</li>
	<li>Distributed services and orchestration: Go, TypeScript, Cloudflare Workers, Nomad, and Consul.</li>
	<li>Remote rendering and streaming: WebRTC and Skia.</li>
	<li>Browser client: TypeScript, WebAssembly, and WebGL.</li>
</ul>
<p><strong>What you will do</strong></p>
<ul>
	<li>Own well-scoped features and improvements from design and implementation through testing, rollout, and production follow-up, with support from experienced teammates.</li>
	<li>Develop and maintain C++ code in our Chromium-based browser, and contribute across distributed services and systems components written in Go, Rust, and TypeScript.</li>
	<li>Debug failures across browser processes, Linux hosts, and distributed services using logs, metrics, traces, and profiling tools.</li>
	<li>Improve session reliability, startup time, interactive latency, and resource efficiency; validate improvements with measurements.</li>
	<li>Write maintainable code, automated tests, and clear design notes; participate in constructive code and design reviews.</li>
	<li>Collaborate with teammates and partner teams, communicate trade-offs and blockers, and incorporate feedback.</li>
	<li>Participate in the team’s production on-call rotation after onboarding, and contribute to incident mitigation and follow-up improvements.</li>
</ul>
<p>This role may require flexibility to be on-call outside of standard working hours to address technical issues as needed.</p>
<p><strong>Desirable Skills, Knowledge, and Experience</strong></p>
<ul>
	<li>Experience delivering and maintaining production software, with practical C++ proficiency and an understanding of memory ownership, resource lifetimes, and concurrency.</li>
	<li>Linux/UNIX fundamentals, including processes, threads, networking, and tools for diagnosing system behavior.</li>
	<li>Working knowledge of data structures, algorithms, and software design.</li>
	<li>Experience developing or operating distributed systems, with an understanding of service-to-service communication, timeouts, retries, partial failure, and basic consistency trade-offs.</li>
	<li>Ability to navigate an unfamiliar codebase, break a defined problem into deliverable steps, and test correctness and failure cases.</li>
	<li>A systematic approach to debugging and performance analysis, using evidence to form and test hypotheses.</li>
	<li>Clear communication, collaborative problem-solving, and a willingness to learn Rust, Go, TypeScript, and the rest of our stack.</li>
</ul>
