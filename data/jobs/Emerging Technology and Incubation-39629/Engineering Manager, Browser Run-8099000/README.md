<h2><span style="font-size: 12pt;">About the Team</span></h2>
<p><span style="font-size: 12pt;">We build the tooling and platform capabilities that power the next generation of AI agents on the Cloudflare Developer Platform. Our goal is to make it easier for agents to interact with the web, and to be observed and controlled while they do it — without giving up performance, scalability or security.</span></p>
<p><span style="font-size: 12pt;">Browser Run is the centre of that work, and it is the product this role owns. It runs full browser sessions on Cloudflare’s global network and lets developers drive them with code or with an agent: a Chrome DevTools Protocol endpoint that any Puppeteer, Playwright or CDP client can connect to from anywhere, Workers bindings, and a REST API for the common jobs — screenshots, PDFs, Markdown extraction, scraping and crawling. On top of that sit session recording and replay, live debugging, and a path for a human to step in when an agent gets stuck.</span></p>
<p><span style="font-size: 12pt;">It is used by external developers building agents, crawlers and scrapers, and by other Cloudflare teams who need a browser they can trust. It is also a billed product on a steep growth curve, which makes capacity, cold-start latency, concurrency limits and abuse protection product problems rather than merely operational ones.</span></p>
<p><span style="font-size: 12pt;">The team’s wider portfolio includes an agent-first browser built on Workers rather than containers, a managed CI platform for the agent development lifecycle, visual regression testing delivered as a service, a pre-rendering service, URL Scanner, and CDNJS. Browser Run is the focus of this role today; there is scope for more of that portfolio to come into it as the role and the team grow.</span></p>
<p><span style="font-size: 12pt;">Browser Run went from an internal rendering tool to a public, billed product, and the surface has not stopped moving — the CDP endpoint, MCP client support, session replay and the REST API all landed inside a year. That pace is the point, and it is the thing this role has to make sustainable.</span></p>
<p><span style="font-size: 12pt;">We are a tight-knit team that communicates and collaborates regularly. We celebrate our achievements, support each other when we make mistakes, and hold each other and our work to the highest standard.</span></p>
