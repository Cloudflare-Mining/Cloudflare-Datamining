<h3>About the Role</h3>
<p>Search is being rebuilt around AI. People increasingly get answers from AI instead of a list of links, agents run dozens of searches to answer a single question, and <a href="https://blog.cloudflare.com/agentic-web/">more than half of the traffic reaching sites on Cloudflare is now automated</a>. Search is shifting from a destination to a utility, and Cloudflare is building the search layer for this agentic Internet.</p>
<p>Agentic Search at Cloudflare gives agents everything they need to find information, whether it lives in a customer’s own data or on the open web. It spans two products: AI Search for internal data, and Web Search API for the open web.</p>
<p><a href="https://developers.cloudflare.com/ai-search/">AI Search</a> (internal data), <a href="https://blog.cloudflare.com/ai-search-ga/">now generally available</a>, is the <a href="https://blog.cloudflare.com/ai-search-agent-primitive/">search primitive for applications and agents</a>. It is a fully managed indexing and retrieval pipeline built on <a href="https://developers.cloudflare.com/workers-ai/">Workers AI</a>, <a href="https://developers.cloudflare.com/vectorize/">Vectorize</a>, <a href="https://developers.cloudflare.com/r2/">R2</a>, and <a href="https://developers.cloudflare.com/browser-run/">Browser Run</a>. Developers connect a website or R2 bucket, or upload their own files, and query them with natural language through a Workers binding, REST API, or MCP server. Under the hood: continuous indexing, hybrid vector and keyword retrieval, reranking, metadata filtering, native multimodal (image) embeddings, and OCR for scanned documents. We use it to power search on our own blog and developer docs.</p>
<p><a href="https://developers.cloudflare.com/web-search/">Web Search API</a> (external data), <a href="https://developers.cloudflare.com/changelog/post/2026-10-02-introducing-web-search-api/">now in open beta</a>, gives agents real-time web context with a single API call. It runs on <a href="https://developers.cloudflare.com/ai-gateway/">AI Gateway</a>, so every search gets the same logging, analytics, billing, and access controls as model inference. Developers can choose from <a href="https://developers.cloudflare.com/web-search/providers/">multiple search providers</a> and always get results back in one normalized format.</p>
<p>Your mission in this role is to make Cloudflare the default place developers and agents go to search, across both their own data and the open web, and eventually in a single call. You’ll also help build a search ecosystem that works for AI companies, site owners, and creators alike.</p>
